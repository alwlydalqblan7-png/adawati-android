# أدواتي — Adawati
تطبيق Android عربي لمعالجة المستندات والصور وQR محليًا.

الإصدار الحالي في هذا الفرع: 0.2.0-rc1، مرشح للاختبار.

- PDF بمقاس A4، ترتيب الصفحات، قص مستطيل وتدوير، أنماط مسح.
- ضغط صور مع مقارنة الحجم ومعالجة اتجاه EXIF.
- QR بترميز UTF-8 للنص العربي.
- ملفاتي، حفظ نسخة خارجية، مشاركة وفتح النتائج.
- معالجة في الخلفية ومسودات محلية؛ لا اتصال بالإنترنت أو إعلانات أو مشتريات.

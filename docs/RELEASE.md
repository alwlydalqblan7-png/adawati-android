# إصدار أدواتي 0.2.0-rc1

هذه نسخة مرشحة للاختبار وليست إعلانًا بأن اختبارات الأجهزة أو قبول المتجر اكتملت.

## البناء
Java 17، Gradle 8.11.1، Android SDK 36 وBuild Tools 35.

```sh
gradle testDebugUnitTest lintDebug assembleDebug assembleRelease bundleRelease
```

`android.yml` يبني APK تجريبيًا وAPK/AAB للإصدار غير موقّعين، ويرفق نتائج الاختبار.
الملفات غير الموقعة ليست مهيأة للتثبيت أو البيع. ملف debug للاختبار فقط.

## التوقيع النهائي
استخدم مفتاح إنتاج قائمًا إذا كان التطبيق قد نُشر به. لا تنشئ مفتاحًا بديلًا لتحديث منشور.
إذا لم يوجد مفتاح إنتاج، أنشئه مرة واحدة على جهاز موثوق واحتفظ بنسخة مشفرة احتياطية خارج GitHub.
لا ترسل كلمة المرور أو المفتاح في المحادثة ولا تضعهما في المستودع.

أضف GitHub Actions secrets:
- ADAWATI_KEYSTORE_BASE64: ملف keystore بترميز base64
- ADAWATI_STORE_PASSWORD
- ADAWATI_KEY_ALIAS
- ADAWATI_KEY_PASSWORD

ثم شغّل `Build signed release`. لا يستخدم البناء توقيع debug بديلًا عند غياب مفتاح الإنتاج.
للبناء المحلي استخدم متغيرات البيئة نفسها لكن ADAWATI_KEYSTORE_PATH لمسار المفتاح بدل BASE64.

انتقال نسخة debug المثبتة إلى توقيع إنتاج مختلف قد يتطلب إزالة النسخة التجريبية؛ صدّر الملفات أولًا.
تزيد versionCode في كل تحديث. ثبّت اسم الحزمة ومفتاح التوقيع للإصدارات التالية.

## بوابة النشر على أجهزة حقيقية
- Android 7/10/13/15/16، هاتف ضعيف وتابلت؛ واجهة عربية وخط كبير ووضع أفقي.
- تثبيت نظيف وتحديث فوق النسخة الموقعة السابقة.
- كاميرا مسموحة/مرفوضة وإلغاء التصوير، QR عربي ورموز تعبيرية وروابط طويلة.
- PDF من 1/10/30 صفحة، مقارنة الترتيب والقص والتدوير وألوان النص، فتح وطباعة A4.
- صور كبيرة، EXIF بمختلف اتجاهاته، PNG شفاف، اختيار صيغة غير مدعومة.
- مقارنة ضغط الصورة، والتأكد أن الناتج لا يزيد عن الأصل.
- حفظ ومشاركة وفتح ملف؛ حفظ خارجي ثم حذف التطبيق والتحقق أن النسخة الخارجية موجودة.
- العودة من الكاميرا، تدوير الشاشة، قتل العملية واستعادة المسودة، مساحة تخزين قليلة.
- لا فقدان ملفات أو انهيار أو تجمد في المهام الأساسية؛ توثيق الجهاز والإصدار ونتيجة كل اختبار.
- قبل Play: مراجعة تقرير pre-launch، توافق 16KB لمكتبات native، Data safety، تصنيف المحتوى، سياسة خصوصية منشورة، لقطات فعلية، وأهلية حساب المطور.

## حدود الإصدار
القص مستطيل يدوي والتدوير بزاوية 90 درجة؛ تصحيح المنظور التلقائي وOCR والمعالجة المجمعة للضغط ليست متاحة.
لا إعلانات أو دفع أو اشتراكات. البيع يحتاج وسيلة قبض وتفعيل واستعادة شراء حقيقية أولًا.
